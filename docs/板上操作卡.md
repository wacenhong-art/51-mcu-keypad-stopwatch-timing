# 实验二板上操作卡

烧录时P5两枚跳线安装；运行时先断电取下P5两帽，再上电。以后再烧录前断电装回。不要在通电时拔插跳线。

## 输入01.00秒并计时

1. K3复位，左右均00.00。
2. 矩阵S1、S2、S1、S1：输入0、1、0、0，左侧01.00。
3. K1确认，液晶READY。
4. K2启动，液晶RUNNING。右侧仍显示00.00是实验要求。
5. 约一秒后再次K2停止。右侧显示停止结果。
6. 若左右相同，八位整体闪烁，液晶MATCH；不同则不闪，液晶NO MATCH。
7. 第三次K2：右侧清零，左侧保留01.00，回到READY。
8. 要再试，直接从第4步开始，不用再输入、也不用按K1。要换目标，先K3复位。

## 每个按键的用途

|按键|用途|
|---|---|
|S1～S10|数字0～9；输入阶段有效|
|K1|四位目标输入完后确认|
|K2|启动→停止→清零，循环三态|
|K3|任何时候重新输入目标并复位|

按下后松开，再按下一个键。只看LCD提示即可操作，不需要电脑串口。
